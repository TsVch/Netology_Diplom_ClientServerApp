# Сетевой чат

Консольный сетевой чат на Java с использованием TCP-соединения. Приложение позволяет нескольким пользователям одновременно подключаться к серверу, обмениваться текстовыми сообщениями и сохранять историю событий в лог-файлах.

## Возможности

- Обмен текстовыми сообщениями между несколькими клиентами.
- Одновременная обработка подключений в отдельных потоках.
- Отправка сообщений всем подключённым пользователям.
- Подключение с указанием имени пользователя.
- Завершение работы клиента командой `/exit`.
- Чтение номера порта из файла настроек `settings.txt`.
- Логирование событий сервера и сообщений клиентов.
- Запись логов с датой и временем.
- Модульные тесты для проверки загрузки настроек.

## Технологии

- Java 21
- Maven
- TCP/IP (`Socket`, `ServerSocket`)
- Многопоточность (`Thread`)
- JUnit Jupiter 5

## Настройка

В корне проекта находится файл `settings.txt`:

```properties
port=8081
```

Параметр `port` задаёт порт, на котором сервер принимает подключения. При необходимости можно изменить его, если выбранный порт свободен.

Сервер и клиенты должны запускаться с рабочей директорией, в которой доступен файл `settings.txt`.

## Запуск приложения

Для запуска потребуется установленный JDK 21 и Maven.

### 1. Сборка проекта

В терминале из корневой директории проекта выполните:

```bash
mvn clean package
```

### 2. Запуск сервера

Запустите класс `org.example.Server` из IntelliJ IDEA или другой IDE.

В консоли появится сообщение о запуске сервера и ожидании подключений.

### 3. Запуск клиентов

Запустите класс `org.example.Client`.

При подключении приложение запросит имя пользователя. После ввода имени можно отправлять сообщения в консоль.

Для общения нескольких пользователей запустите несколько экземпляров клиента. В IntelliJ IDEA для этого может потребоваться включить параметр `Allow multiple instances` в настройках конфигурации запуска.

### 4. Обмен сообщениями

Все сообщения отправляются серверу и рассылаются подключённым пользователям.

Для завершения работы клиента введите:

```text
/exit
```

Отключение одного клиента не должно останавливать сервер или работу остальных клиентов.

## Логирование

События и сообщения записываются в текстовые файлы с датой и временем.

- `server.log` — журнал работы сервера.
- `client-<имя>.log` — журнал соответствующего клиента, где имя приведено к допустимому имени файла.

Файлы создаются автоматически при первой записи. Новые записи добавляются в конец файла.

## Тестирование

Для запуска автоматических тестов выполните:

```bash
mvn test
```

Тесты `SettingsTest` проверяют чтение номера порта, обработку отсутствующего параметра и отклонение порта за допустимыми границами.

## Протокол обмена

Обмен данными выполняется по TCP. Каждая строка передаётся отдельно:

1. Первая строка от клиента содержит имя пользователя.
2. Последующие строки содержат сообщения чата.
3. Строка `/exit` завершает соединение клиента.

Для корректной работы сервер и клиент используют UTF-8.

## Ограничения текущей версии

- Клиент подключается к серверу по адресу `localhost`; для подключения с других компьютеров потребуется настроить адрес сервера.
- История сообщений хранится в текстовых логах и не загружается обратно в чат при подключении.
- Авторизация пользователей и шифрование сообщений не реализованы.
